# たんいドリル（小4・単位）

小学4年生向けの、単位（長さ・重さ・かさ・時間・面積）の練習ドリル。タブレット（iPad）で使う PWA。
サーバー・ログインは不要で、HTML / CSS / JS だけで動く。公開URL: https://e-yana.github.io/tani-drill/

## できること
- 「きょうの 10もん」: 未出題の問題と、復習が必要な問題を合わせて1日10問出す
- 数字を入れる問題は画面のテンキー、単位えらびは3択
- まちがえた問題は、その回のうちにもう一度出る（最大3回まで）
- 全100問（7つの段階: 3年のふくしゅう → 4年の小数・面積・単位えらび・文章題）

## 使い方
1. ホームの「きょうの 10もん」を押す
2. 答えたら「せいかい！」か「ざんねん」が出る。「つぎへ」で進む
3. 10問おわると結果が出る

## タブレットで使う方法
- このフォルダで `python3 -m http.server` を起動し、同じネットワークのタブレットから `http://<Macのアドレス>:8000/` を開く
- 公開URLを Safari で開き、共有ボタンから「ホーム画面に追加」を選ぶ
- 一度開けば、オフラインでも動く

## データについて
学習の記録は、その端末のブラウザ（localStorage）だけに保存される。外部には送らない。
記録が読めなくなったときは、元の文字列を別のキー（`taniDrill_v1_backup_日付`）に退避してから新しく始める。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` / `app.js` | 画面 |
| `logic.js` | 出題・採点・保存形式（DOM に触れない） |
| `data.js` | 問題100問（自動生成。直接編集しない） |
| `gen/make_data.py` | 問題の元。ここから data.js を作る |
| `gen/test_logic.js` | logic.js のテスト（`node gen/test_logic.js`） |
| `gen/make_icons.py` | アイコン作成 |
| `manifest.webmanifest` / `sw.js` / `icons/` | PWA 用 |

## 問題の直し方
1. `gen/make_data.py` の問題を直す（id は変えない・再利用しない）
2. `python3 gen/make_data.py data.js` で data.js を作り直す
3. `app.js` の `APP_VERSION` と `sw.js` の `CACHE` の番号を対で上げる

## きろくの ほぞん（バックアップ）
ホームの「きろくを ほぞん」→共有シートで「ファイルに保存」→Googleドライブ。端末が壊れても残り、進み具合・苦手を外から読める。
戻すときは「ふくげん」からそのファイルを選ぶ（今の記録は退避されてから置き換わる）。
